Toolkitv0.2

Industry standard tools and shortcuts for Blender. Maya-style navigation and selection, fast interactive modeling tools, pie menus and a game-art toolkit. Every feature can be turned on or off.

Get it on Blender Extensions Shortcut cheat sheet Source on GitHub

Sections

Industry Standard

Alt navigation, double-click select island, instant delete, Maya pivot, retopology toggle.

Modeling Tools

Merge tool, Fast Loop Cut, Cutter, Fast Mirror, Bevel, Array, Solidify, booleans.

Pie Menus

Add objects, add modifiers, cursor, flatten and workspace pies.

Toolkit Panel

N-panel with object and edit tools, CAD Decimate, Auto LOD, Polycount List and baking helpers.

UV

Smart UV Sync, Maya-like UV cut, unwrap in place, quick pack and more.

Extras

Fast merge/connect, modifier panel shortcuts, attribute operations, legacy shortcuts.

Preferences

Settings, keymaps and the Rebind tab.

Shortcut Cheat Sheet

Every default shortcut on one page.
