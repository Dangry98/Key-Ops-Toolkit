Today

  • Tab called "Toolkit", a name other add-ons also use. The UV editor tab name is a separate setting.
  • A row of unlabelled icons switches sub-panels on and off through toolkit_panel_mode.
  • Quick Bake Name, Retopology, LOD and CAD Decimate are separate panels in the same tab, always shown.

Proposed

  • One "Key Ops" tab name for the 3D View and UV editor (renamable).
  • Native bl_parent_id subpanels, so collapse, reorder and pin come for free.
  • A mode-aware poll() per section, and Pipeline grouped and closed by default.
  • The header holds the cheat sheet and a ⋯ menu: Pause shortcuts, Preferences, Docs.

What changes and why

The common complaint is that the add-on does too much the moment it is installed. The redesign separates having a feature from having its shortcuts, labels every key by its impact, and lets a first-run choice decide how much changes.

Compliance blocker. The extensions.blender.org rules this repo tracks forbid editing keyconfigs.user, rebind operators, conflict resolvers, and writing preferences or themes. The current Rebind tab, the pie-timeout button, Maya Pivot's Grease Pencil tweak and Retopology's theme swap all do this. In 1.0 they become opt-in keyconfigs.addon items, or text-only advice.

One registry instead of four places

Today a feature means a BoolProperty, a draw tuple, a branch in a 250-line if/elif in __init__.py, and an entry in the keymap source list in pref_utils.py. In 1.0 it is one declaration.

@dataclass(frozen=True)
class Key:
    keymap: str; idname: str; type: str; value: str = "PRESS"
    ctrl: bool = False; shift: bool = False; alt: bool = False
    props: tuple = ()
    replaces: str = ""          # "Delete menu" → amber badge; "" → FREE

@dataclass(frozen=True)
class Feature:
    id: str; name: str; category: str; description: str; docs: str
    module: str                 # register()/unregister() for classes only, no keymaps
    keys: tuple = ()
    key_styles: frozenset = frozenset({"INDUSTRY"})
    experimental: bool = False

FEATURES = (
    Feature("auto_delete", "Auto Delete", "MODELING",
            "Delete in Edit Mode removes what you selected, with no menu.",
            "industry-standard.html#auto-delete", "operators.auto_delete",
            keys=(Key("Mesh", "keyops.auto_delete", "DEL", replaces="Delete menu"),)),
    ...
)

def register_keys(f):
    kc = bpy.context.window_manager.keyconfigs.addon
    if kc is None:              # background mode, guarded once for everyone
        return
    for k in f.keys:
        km = kc.keymaps.new(k.keymap, space_type="EMPTY")
        kmi = km.keymap_items.new(k.idname, k.type, k.value, ctrl=k.ctrl, shift=k.shift, alt=k.alt)
        for n, v in k.props: setattr(kmi.properties, n, v)
        _live[f.id].append((km, kmi))
